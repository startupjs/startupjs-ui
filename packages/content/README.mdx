# Content

A parent container for the main content area of your app or website. You can pass custom `style` to the root element and provide content as `children`.

It applies sensible default horizontal padding and limits the maximum width to what is generally considered a comfortable reading width -- `768px` (roughly the width of a tablet in portrait mode).

```jsx
import { Content } from 'startupjs-ui'
```

## Simple Example

By default, Content has left and right padding of `16px`.

```jsx example
const contentStyle = {
  backgroundColor: '#2962FF'
}
const divStyle = {
  height: 200,
  backgroundColor: '#00AED6',
  alignItems: 'center',
  justifyContent: 'center'
}
return (
  <Content style={contentStyle}>
    <Div style={divStyle}>
      <Span>content</Span>
    </Div>
  </Content>
)
```

## No horizontal paddings

Pass the `pure` prop to remove the left and right padding. This keeps the maximum width constraint (`768px` by default) while letting you handle internal padding yourself.

This is useful for lists, tables, or other components that need to span edge-to-edge on small screens, while still limiting the maximum content width on larger screens.

```jsx example
const contentStyle = {
  backgroundColor: '#2962FF'
}
const divStyle = {
  height: 200,
  backgroundColor: '#00AED6',
  alignItems: 'center',
  justifyContent: 'center'
}
return (
  <Content style={contentStyle} pure>
    <Div style={divStyle}>
      <Span>content</Span>
    </Div>
  </Content>
)
```

## Vertical paddings

Pass the `padding` prop to add equal top and bottom padding. When set to `true`, it uses a default spacing value. You can also pass a number to specify a custom padding amount.

```jsx example
const contentStyle = {
  backgroundColor: '#2962FF'
}
const divStyle = {
  height: 200,
  backgroundColor: '#00AED6',
  alignItems: 'center',
  justifyContent: 'center'
}
return (
  <Content style={contentStyle} padding>
    <Div style={divStyle}>
      <Span>content</Span>
    </Div>
  </Content>
)
```

## Full space

The `full` prop makes the Content expand to fill all available space along the parent's main flexbox axis.

```jsx example
const divStyle = {
  height: 200,
  backgroundColor: '#2962FF'
}
const contentStyle = {
  backgroundColor: '#00AED6',
  alignItems: 'center',
  justifyContent: 'center'
}
return (
  <Div>
    <Div style={divStyle}>
      <Content style={contentStyle}>
        <Span>Content without full</Span>
      </Content>
    </Div>
    <Br />
    <Div style={divStyle}>
      <Content style={contentStyle} full>
        <Span>Content with full</Span>
      </Content>
    </Div>
  </Div>
)
```

## Max width

By default, Content limits its max-width to `768px` (the `'tablet'` preset). Since the layout is mobile-first, you can scale up to larger screens using the `width` prop. The available presets are: `'mobile'`, `'tablet'` (default), `'desktop'`, `'wide'`, and `'full'`. See the Sandbox section below to try each one.

You can also tune the width presets app-wide by overriding `--Content-width-mobile`, `--Content-width-tablet`, `--Content-width-desktop`, or `--Content-width-wide` in your provider style.

```jsx example
const contentStyle = {
  backgroundColor: '#2962FF'
}
const divStyle = {
  height: 200,
  backgroundColor: '#00AED6',
  alignItems: 'center',
  justifyContent: 'center'
}
return (
  <Div>
    <Content
      style={contentStyle}
      width='mobile'
      padding
    >
      <Div style={divStyle}>
        <Span>Mobile</Span>
      </Div>
    </Content>
    <Br />
    <Content
      style={contentStyle}
      padding
    >
      <Div style={divStyle}>
        <Span>Tablet (default)</Span>
      </Div>
    </Content>
    <Br />
    <Content
      style={contentStyle}
      width='desktop'
      padding
    >
      <Div style={divStyle}>
        <Span>Desktop</Span>
      </Div>
    </Content>
    <Br />
    <Content
      style={contentStyle}
      width='wide'
      padding
    >
      <Div style={divStyle}>
        <Span>Full Width</Span>
      </Div>
    </Content>
  </Div>
)
```

## Styling reference

Use these names from `StartupjsProvider style` or another CSSX provider style layer for app-wide overrides.
For the full theming model, see the [Styling and theming](/docs/Styling) guide.

### Parts

| Part | Description |
| --- | --- |
| `root` | Root element. |

### CSS variables

| Variable | Default | Description |
| --- | --- | --- |
| `--Content-gutter` | `calc(var(--spacing) * 4)` | Controls the gutter. |
| `--Content-width-mobile` | `var(--breakpoint-sm)` | Controls the width mobile. |
| `--Content-width-tablet` | `var(--breakpoint-md)` | Controls the width tablet. |
| `--Content-width-desktop` | `var(--breakpoint-lg)` | Controls the width desktop. |
| `--Content-width-wide` | `var(--breakpoint-xl)` | Controls the width wide. |
