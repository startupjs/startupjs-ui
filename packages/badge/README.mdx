# Badge

Badges are small status descriptors that attach to UI elements, such as icons or buttons. They are commonly used to display counts (like unread messages) or to indicate a change in state.

The component supports `style`, `badgeStyle`, `labelStyle`, and `iconStyle` props for per-instance overrides. For app-wide customization, target `Badge`, `Badge:part(badge)`, `Badge:part(label)`, and `Badge:part(icon)` from provider styles.

```js
import { Badge } from 'startupjs-ui'
```

## Simple example

```jsx example
return (
  <Badge label='10'>
    <Icon icon={faEnvelope} size={40} />
  </Badge>
)
```

## Sizes

Badges come in three different sizes: `'s'`, `'m'`, and `'l'`. The default size is `'m'`.

```jsx example
return (
  <Div row>
    <Badge label='16' size='s'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
    <Badge style={{ marginLeft: 16 }} label='20'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
    <Badge style={{ marginLeft: 16 }} label='24' size='l'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
  </Div>
)
```

## Variants

There are two variants: `'default'` and `'dot'`. The `'default'` variant displays a label and is used by default. The `'dot'` variant renders the badge as a small dot, which is useful for indicating that something has changed without showing a specific count. When `variant='dot'` is set, the `size` prop is ignored.

```jsx example
return (
  <Div row>
    <Badge label='10'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
    <Badge style={{ marginLeft: 16 }} variant='dot'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
  </Div>
)
```

## Colors

The default color is `'primary'`. You can change it by passing a CSSX color token, such as `success`, `warning`, or `error`, to the `color` prop. Tokens resolve through variables like `--color-primary`.

```jsx example
return (
  <Badge color='error' label='10'>
    <Icon icon={faEnvelope} size={40}/>
  </Badge>
)
```

## Position

The badge can be positioned at the `'top'` or `'bottom'` of its child element. The default position is `'top'`.

```jsx example
return (
  <Div row>
    <Badge label='10'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
    <Badge style={{ marginLeft: 16 }} position='bottom' label='10'>
      <Icon icon={faEnvelope} size={40} />
    </Badge>
  </Div>
)
```

## Icons

An icon can be displayed inside the badge using the `icon` prop.

```jsx example
return (
  <Badge icon={faThumbsUp} label='10+' color='success'>
    <Icon icon={faEnvelope} size={40} />
  </Badge>
)
```

## Counter

When the `label` prop is a number, you can use the `max` prop to cap the displayed value. If `label` exceeds `max`, the badge shows the max value followed by a `+` sign.

```jsx example
return (
  <Badge label={1000} max={100}>
    <Icon icon={faEnvelope} size={40} />
  </Badge>
)
```

## Styling reference

Use these names from `StartupjsProvider style` or another CSSX provider style layer for app-wide overrides.
For the full theming model, see the [Styling and theming](/docs/Styling) guide.

### Parts

| Part | Description |
| --- | --- |
| `root` | Root element. |
| `badge` | Badge body. |
| `icon` | Primary icon. |
| `label` | Label text. |

### CSS variables

| Variable | Default | Description |
| --- | --- | --- |
| `--Badge-size-s` | `1rem` | Controls the small size. |
| `--Badge-size-m` | `1.25rem` | Controls the medium size. |
| `--Badge-size-l` | `1.5rem` | Controls the large size. |
| `--Badge-size-dot` | `0.5rem` | Controls the size dot. |
| `--Badge-border-color` | `var(--color-background)` | Controls the border color. |
| `--Badge-font-size-s` | `0.625rem` | Controls the small font size. |
| `--Badge-line-height-s` | `0.75rem` | Controls the small line height. |
| `--Badge-font-size-m` | `0.75rem` | Controls the medium font size. |
| `--Badge-line-height-m` | `1rem` | Controls the medium line height. |
| `--Badge-font-size-l` | `1rem` | Controls the large font size. |
| `--Badge-line-height-l` | `1.25rem` | Controls the large line height. |
| `--Badge-padding-x-s` | `calc(var(--spacing) * 1)` | Controls the small padding horizontal. |
| `--Badge-padding-x-m` | `calc(var(--spacing) * 1)` | Controls the medium padding horizontal. |
| `--Badge-padding-x-l` | `calc(var(--spacing) * 2)` | Controls the large padding horizontal. |
| `--Badge-icon-gap` | `calc(var(--spacing) * 0.5)` | Controls the icon gap. |
