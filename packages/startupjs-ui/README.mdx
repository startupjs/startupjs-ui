# startupjs-ui

A modular UI component library for StartupJS. It provides universal React Native and web UI components. You can import any component directly from `startupjs-ui` or from individual subpaths like `startupjs-ui/Button`.

```js
import { Button, Form } from 'startupjs-ui'
// or
import Button from 'startupjs-ui/Button'
import Form from 'startupjs-ui/Form'
```

## UiProvider

UiProvider wires up CSSX theming and shared UI infrastructure (portal, toasts, dialogs). Its defaults are layered from CSSX Tailwind tokens, CSSX shadcn semantic tokens, and StartupJS UI component tokens. It is plugged in automatically as a plugin into `StartupjsProvider`, so the only thing you need at the root of your app is:

```jsx
import { StartupjsProvider } from 'startupjs'
import { Stack } from 'expo-router'

export default function RootLayout () {
  return (
    <StartupjsProvider>
      <Stack />
    </StartupjsProvider>
  )
}
```

You can pass CSSX theme overrides through `StartupjsProvider style`:

```jsx
import { css } from 'startupjs'

const style = css`
  :root {
    --color-primary: #0000ff;
    --color-error: #ff0000;
  }

  Button {
    border-radius: 12px;
  }

  Button:hover {
    background-color: #0000cc;
  }
`

<StartupjsProvider
  style={style}
  routerPortal
>
  <Stack />
</StartupjsProvider>
```

### Options

- `style` -- CSSX style overrides for UI components. Use `:root` for theme variables, utility classes for shared styles, and component tag selectors such as `Button` plus `:part()` for component defaults.
- `routerPortal` -- when `true`, mounts an additional `Portal.Provider` inside the router tree. Use it when portal content can render router-aware components such as links or navigation actions.

Component color props accept CSSX color tokens such as `'primary'`, which map to variables like `--color-primary`. Use `var(--your-variable)` or normal CSS colors when a raw CSS value is clearer.

For the full customization model, see the Styling guide in the docs. Each component page also includes a styling reference table with its parts and component-specific CSS variables.
