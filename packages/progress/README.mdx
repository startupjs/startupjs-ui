# Progress

Progress displays the completion status of a process, such as a file upload or download. The `value` prop sets the progress percentage (0 to 100, defaults to `0`).

The component supports two visual variants via the `variant` prop: `'linear'` (default) and `'circular'`. You can customize the bar height with the `width` prop, the track shape with the `shape` prop (defaults to `'rounded'`), and apply custom styles using `style` for the wrapper, `progressStyle` for the progress track, and `fillerStyle` for the filled portion.

```jsx
import { Progress } from 'startupjs-ui'
```

## Simple example

```jsx example
return (
  <Progress value={10} />
)
```

## Interactive

The progress bar animates smoothly as the `value` changes.

```jsx example
const [value, setValue] = useState(0)
const [startProgress, setStartProgress] = useState(false)
const [countdown, setCountdown] = useState(false)

useEffect(() => {
  let interval
  if (startProgress) {
    interval = setInterval(() => {
      setValue(v => {
        const nextValue = countdown ? v - 1 : v + 1
        if (nextValue === 100 || nextValue === 0) {
          setCountdown(!countdown)
        }
        return nextValue
      })
    }, 100)
  }
  return () => clearInterval(interval)
}, [startProgress, countdown])

return (
  <>
    <Progress value={value} />
    <Br />
    <Button onPress={() => setStartProgress(!startProgress)}>
      {startProgress ? 'Stop' : 'Start'}
    </Button>
  </>
)
```

## Caption

Pass `children` to display a label below the progress bar.

```jsx example
return (
  <Progress value={50}>50 of 100</Progress>
)
```

## Styling reference

Use these names from `StartupjsProvider style` or another CSSX provider style layer for app-wide overrides.
For the full theming model, see the [Styling and theming](/docs/Styling) guide.

### Parts

| Part | Description |
| --- | --- |
| `root` | Root element. |
| `filler` | Progress fill. |
| `progress` | Progress track. |

### CSS variables

| Variable | Default | Description |
| --- | --- | --- |
| `--Progress-width` | `0.25rem` | Controls the width. |
| `--Progress-duration` | `300` | Controls the duration. |
| `--Progress-track-bg` | `var(--color-muted)` | Controls the track background. |
| `--Progress-filler-bg` | `var(--color-success)` | Controls the filler background. |
| `--Progress-circular-size` | `2.5rem` | Controls the circular size. |
| `--Progress-label-margin-top` | `2px` | Controls the label margin top. |
| `--Progress-label-font-size` | `var(--text-xs)` | Controls the label font size. |
| `--Progress-label-line-height` | `1rem` | Controls the label line height. |
