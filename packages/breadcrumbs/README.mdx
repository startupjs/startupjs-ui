# Breadcrumbs

Breadcrumbs show the current page's location within a navigational hierarchy and let users navigate back through parent pages.

```jsx
import { Breadcrumbs } from 'startupjs-ui'
```

## Simple example

Pass an array of route objects to the `routes` prop. Each route has a `to` path and a `name` label. The last route in the array is displayed as the active (current) page and is not clickable.

```jsx example
return (
  <Breadcrumbs
    routes={[
      {
        to: '#startupjs',
        name: 'StartupJs'
      },
      {
        to: '#docs',
        name: 'Docs'
      },
      {
        to: '#component',
        name: 'Component'
      },
      {
        to: '#Breadcrumbs',
        name: 'Breadcrumbs'
      }
    ]}
  />
)
```

## Custom separator

The separator between routes is `/` by default. You can change it by passing a string or a custom React node to the `separator` prop.

```jsx example
return (
  <Breadcrumbs
    separator='>'
    routes={[
      {
        to: '#startupjs',
        name: 'StartupJs'
      },
      {
        to: '#docs',
        name: 'Docs'
      },
      {
        to: '#component',
        name: 'Component'
      },
      {
        to: '#Breadcrumbs',
        name: 'Breadcrumbs'
      }
    ]}
  />
)
```

## Icons

Each route object accepts an optional `icon` prop. To change the icon's position relative to the label, use the `iconPosition` prop on the Breadcrumbs component (`left` by default).

```jsx example
return (
  <Breadcrumbs
    separator='>'
    routes={[
      {
        to: '#startupjs',
        name: 'StartupJs',
        icon: faRocket
      },
      {
        to: '#docs',
        name: 'Docs',
        icon: faBook
      },
      {
        to: '#component',
        name: 'Component',
        icon: faGift
      },
      {
        to: '#Breadcrumbs',
        name: 'Breadcrumbs',
        icon: faAnchor
      }
    ]}
  />
)
```

## Sizes

The `size` prop controls the dimensions of the text and icons. The default value is `m`. Available sizes are `s`, `m`, and `l`. See all available values in the Sandbox section at the bottom of the page.

```jsx example
return (
  <Div>
    <Breadcrumbs
      size='l'
      routes={[
        {
          to: '#startupjs',
          name: 'StartupJs'
        },
        {
          to: '#docs',
          name: 'Docs'
        },
        {
          to: '#component',
          name: 'Component'
        },
        {
          to: '#Breadcrumbs',
          name: 'Breadcrumbs'
        }
      ]}
    />
    <Br />
    <Breadcrumbs
      size='s'
      routes={[
        {
          to: '#startupjs',
          name: 'StartupJs'
        },
        {
          to: '#docs',
          name: 'Docs'
        },
        {
          to: '#component',
          name: 'Component'
        },
        {
          to: '#Breadcrumbs',
          name: 'Breadcrumbs'
        }
      ]}
    />
  </Div>
)
```

## Navigation behavior

By default, clicking a breadcrumb pushes a new entry onto the browser history stack. Set the `replace` prop to `true` to replace the current history entry instead, which prevents the user from navigating back to the replaced page.

## Custom styles

Use CSS variables for theme-level customization:

```css
:root {
  --Breadcrumbs-current-color: var(--color-primary);
  --Breadcrumbs-link-color: var(--color-muted-foreground);
  --Breadcrumbs-separator-color: var(--color-muted-foreground);
}
```

Use `Breadcrumbs` tag overrides and `Breadcrumbs:part(root)` for global overrides, or the `style` prop for one-off root styles.

### CSS variables

| `--Breadcrumbs-separator-color` | `var(--color-muted-foreground)` | Controls the separator color. |

| `--Breadcrumbs-font-size-xs` | `0.625rem` | Controls the xs font size. |
