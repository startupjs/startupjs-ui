# Tricks with styles

This chapter covers useful style conventions and mixins available in StartupJS.

## Units

StartupJS uses an 8px grid. One unit is `1u = 8px`.

```styl
.card
  padding 2u 3u  // 16px 24px
  margin 3u      // 24px
```

Use pixel values only when you need exact 1px borders or hairline adjustments.

## Mixins

### `font()`

`font()` expands to `font-size` and `line-height` values.

| Value   | font-size | line-height |
| ------- | --------- | ----------- |
| h1      | 72px      | 96px        |
| h2      | 48px      | 64px        |
| h3      | 36px      | 48px        |
| h4      | 24px      | 32px        |
| h5      | 20px      | 28px        |
| h6      | 16px      | 24px        |
| body1   | 16px      | 24px        |
| body2   | 14px      | 20px        |
| caption | 12px      | 16px        |

### `shadow()`

`shadow(level)` normalizes shadows across web and native. Levels range from 0 to 4.

| Level | Styles |
| ----- | ------ |
| 0     | box-shadow: none; elevation: 0 |
| 1     | box-shadow: 0 1px 2px var(--color-shadow-main); elevation: 3 |
| 2     | box-shadow: 0 3px 5px var(--color-shadow-main-strong); elevation: 6 |
| 3     | box-shadow: 0 5px 8px var(--color-shadow-main-strong); elevation: 12 |
| 4     | box-shadow: 0 8px 12px var(--color-shadow-main); elevation: 18 |

### `radius()`

`radius()` keeps border radii consistent:

| Value  | border-radius |
| ------ | ------------- |
| m      | 4px           |
| l      | 8px           |
| circle | 9999px        |

## Screen and platform mixins

| Mixin      | Environment                  |
| ---------- | ---------------------------- |
| +tablet()  | min-width >= 768px           |
| +desktop() | min-width >= 1024px          |
| +wide()    | min-width >= 1280px          |
| +portrait()| portrait orientation         |
| +landscape()| landscape orientation       |
| +web()     | web only                     |
| +android() | Android only                 |
| +ios()     | iOS only                     |
| +native()  | native (not web)             |

Example:

```styl
.card
  padding 2u
  margin 0 2u
  +tablet()
    padding 3u
    margin 0 3u
  +desktop()
    padding 4u
    margin 0 4u
```

## The `$UI` object

`$UI` holds global design tokens. You can override it in `styles/index.styl` to customize your app.

Common fields:

- `$UI.palette` - base palette swatches
- `$UI.colors` - derived semantic colors
- `$UI.shadows` - shadow presets
- `$UI.media` - breakpoints for mixins
- `$UI.fontFamilies` - font families for body and headings
- `$UI.fontSizes` - typography sizes
- `$UI.lineHeights` - typography line heights

### Extending `$UI`

Use `merge` to add or override values:

```styl
$UI = merge($UI, {
  colors: {
    primary: #4a76a8,
    warning: #880000,
    pink: #fc69ff
  },
  Button: {
    heights: {
      xxl: 10u
    }
  }
}, true)
```

## Export styles to JavaScript

Use `:export` to expose values from Stylus to JS:

```styl
.root
  height: $this.height
  background-color: $this.bgColor

:export
  colors: $UI.colors
  foobar: 42
```

```js
import STYLES from './index.styl'

const { colors, foobar } = STYLES
```
