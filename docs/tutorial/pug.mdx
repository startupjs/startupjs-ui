# Pug

StartupJS supports the Pug templating language. It is optional, but it can make your code more concise. If you prefer JSX, you can skip this chapter.

Pug is already supported by StartupJS. You only need to configure your IDE:
https://github.com/startupjs/startupjs#ide-configuration

## Syntax basics

- Nesting is defined by indentation
- Classes use `.className`
- Ids use `#id`
- Attributes go in parentheses

## Tags and classes

**Pug**

```pug
Content
  H1 TODO List
  Card
    Span Learn StartupJS
```

**JSX**

```jsx
<Content>
  <H1>TODO List</H1>
  <Card>
    <Span>Learn StartupJS</Span>
  </Card>
</Content>
```

Add classes:

```pug
Content.root
  H1.title TODO List
  Card.todo
    Span.todoTitle Learn StartupJS
```

```jsx
<Content className='root'>
  <H1 className='title'>TODO List</H1>
  <Card className='todo'>
    <Span className='todoTitle'>Learn StartupJS</Span>
  </Card>
</Content>
```

## Attributes

```pug
Button(size='m') Add
```

```jsx
<Button size='m'>Add</Button>
```

With classes:

```pug
Button.submit(size='m') Add
```

```jsx
<Button className='submit' size='m'>Add</Button>
```

For many props, use a multiline block:

```pug
Button(
  icon=faTimes
  iconColor='error'
  size='s'
  onPress=() => removeTodo(todo.id)
)
```

Note: in Pug you do not need `{}` around JavaScript expressions.

## Loops

Use `each` to render arrays:

```pug
const [todos] = useQuery('todos', {})

Content(padding)
  H1 Todo List
  each todo, index in todos
    Card(key=todo.id)
      Span= todo.title
```

## Conditions

```pug
if todos.length
  each todo in todos
    Card(key=todo.id)
      Span= todo.title
else
  Span Task list is empty
```

You can also write:

```pug
unless value
  Span Empty
```

## Interpolation

```pug
const title = 'Todo List'

Span= title
Span My app: #{title}
```
