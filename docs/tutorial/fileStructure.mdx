# Project structure

When you run `npx startupjs init myapp`, you get a full project with a standard layout. This chapter explains the key folders and files.

## Platform-specific files

StartupJS uses React Native, so each file can target both web and native. You can split files per platform:

- `*.web.js` for web-only files
- `*.js` for shared or native files

If a `*.web.js` file exists, it is used for web builds; otherwise the `*.js` file is used everywhere.

### When to use platform files

1. A library is only available on one platform.
2. A screen has major UX differences between web and native (use sparingly).

## Application entry point

The `Root` folder contains the top-level app entry. Example:

```jsx
import { BASE_URL } from '@env'
import init from 'startupjs/init'
import App from 'startupjs/app'
import { observer, model } from 'startupjs'
import { Platform } from 'react-native'
import orm from '../model'
import * as main from '../main'

if (Platform.OS === 'web') window.model = model

init({ baseUrl: BASE_URL, orm })

export default observer(() => (
  <App apps={main} />
))
```

Key points:

- `init({ baseUrl, orm })` connects to the server and sets up ORM.
- `App apps={main}` mounts your app(s).
- `main` is the default app; you can add more.

## ORM models

The `model` (or `models`) folder defines ORM classes and connects them to collection paths.

```js
import TodosModel from './TodosModel'
import TodoModel from './TodoModel'

export default function (racer) {
  racer.orm('todos', TodosModel)
  racer.orm('todos.*', TodoModel)
}
```

Use the **plural** model for collection methods and the **singular** model for document-specific methods.

### Extending models

```js
import { BaseModel } from 'startupjs/orm'

export default class TodosModel extends BaseModel {
  async addTodo (data) {
    const id = this.id()
    const createdAt = Date.now()

    await this.add({
      id,
      createdAt,
      ...data
    })

    return id
  }
}
```

Use it anywhere:

```jsx
const $todos = useModel('todos')

function addTodo () {
  $todos.addTodo({
    title: 'New todo',
    completed: false
  })
}
```

## Apps

Every project starts with one app: `main`. You can add additional apps that share the same server and database.

Inside an app, the key files are:

### `routes.js`

```js
export default (components = {}) => [
  {
    path: '/',
    exact: true,
    component: components.PHome
  },
  {
    path: '/about',
    exact: true,
    component: components.PAbout
  }
]
```

### `index.js`

```js
import * as pages from './pages'
import getRoutes from './routes'

export { default as Layout } from './Layout'
export const routes = getRoutes(pages)
```

### `Layout`

`Layout` wraps every page in the app. This is where you place shared UI like headers, footers, and sidebars.
