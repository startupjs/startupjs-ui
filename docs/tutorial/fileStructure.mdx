# Project structure

When you run `npx startupjs init myapp`, you get a project with a standard layout. This chapter explains the key folders and files.

## Platform-specific files

StartupJS uses React Native, so your code runs on web, iOS, and Android by default. If you need platform-specific behavior, you can split files:

- `*.web.js` -- used only for web builds
- `*.js` -- used everywhere (shared or native)

If both `Something.web.js` and `Something.js` exist, the web bundler uses the `.web.js` version while native uses the `.js` version.

### When to use platform files

1. A library only works on one platform (for example, a web-only date picker).
2. A screen has major UX differences between web and mobile. Use this sparingly -- most code should be shared.

## Application entry point

The `Root` folder contains the top-level app entry. A typical entry file looks like this:

```jsx
import { BASE_URL } from '@env'
import init from 'startupjs/init'
import App from 'startupjs/app'
import { observer } from 'startupjs'
import * as main from '../main'

init({ baseUrl: BASE_URL })

export default observer(() => (
  <App apps={main} />
))
```

Key points:

- `init({ baseUrl })` connects to the server and sets up the framework.
- `App` mounts your application(s).
- `main` is the default app. You can add more apps that share the same server and database.

## Apps

Every project starts with one app called `main`. Inside an app folder, the key files are:

### `routes.js`

Defines the URL-to-component mapping:

```js
export default (components = {}) => [
  {
    path: '/',
    exact: true,
    component: components.PHome
  },
  {
    path: '/about',
    exact: true,
    component: components.PAbout
  }
]
```

### `index.js`

Exports the app's routes and layout:

```js
import * as pages from './pages'
import getRoutes from './routes'

export { default as Layout } from './Layout'
export const routes = getRoutes(pages)
```

### `Layout`

`Layout` wraps every page in the app. This is where you place shared UI like headers, footers, and sidebars.

## Pages

Each page is a component in the `pages/` folder. By convention, page component names start with `P`:

```
main/
  pages/
    PHome/
      index.jsx
      index.styl
    PAbout/
      index.jsx
      index.styl
```

Each page folder typically contains:
- `index.jsx` -- the page component
- `index.styl` -- styles for the page (using Stylus)
