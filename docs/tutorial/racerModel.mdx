# Racer model

StartupJS uses Racer + ShareDB for realtime data sync. Racer exposes a **model** API that lets you read and mutate data from the client or server with the same interface.

## Why it matters

- Realtime updates across all subscribed clients
- Offline-first behavior (changes apply locally, then sync)
- Conflict resolution with operational transforms
- A single API on client and server

## What is a model?

Think of a model as a pointer to a part of your database. A model can point to:

- a collection (`todos`)
- a document (`todos.<id>`)
- a nested field (`todos.<id>.title`)

The model then provides methods like `get`, `set`, `add`, and `del`.

By convention, models are named with a `$` prefix: `$todos`, `$todo`.

## Getting a model manually

```js
const $todos = model.scope('todos')
await $todos.subscribe()

// Read and write
const list = $todos.get()
$todos.add({ title: 'Learn Racer', completed: false })

$todos.unsubscribe()
```

> Tip: when you use aggregations or `$count`, read the value with `getExtra()` instead of `get()`.

## Collection model (with hooks)

Hooks make this easier:

```jsx
const [todos, $todos] = useQuery('todos', {})

$todos.add({ title: 'New todo', completed: false })
```

`$todos` points to the collection, so you can do `$todos.at(todo.id)` to access a single document.

## Document model

```jsx
function Todo ({ id }) {
  const [todo, $todo] = useDoc('todos', id)

  return (
    <Card>
      <Span>{todo.title}</Span>
      <Checkbox
        value={todo.completed}
        onChange={value => $todo.set('completed', value)}
      />
    </Card>
  )
}
```

Useful document methods:

```js
$todo.set('title', 'New title')
$todo.setEach({ priority: 'high', updatedAt: Date.now() })
$todo.del()
```

## Custom model methods

You can add your own methods by extending `BaseModel`:

```js
import { BaseModel } from 'startupjs/orm'

export default class TodosModel extends BaseModel {
  async addTodo (data) {
    const id = this.id()
    const createdAt = Date.now()

    await this.add({
      id,
      createdAt,
      ...data
    })

    return id
  }
}
```

Register it in `model/index.js` with `racer.orm('todos', TodosModel)`.
